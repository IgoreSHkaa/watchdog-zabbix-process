### Мониторинг новых процессов через Zabbix

Bash-скрипт для обнаружения новых или несанкционированных процессов на Linux-сервере с автоматической отправкой алертов в Zabbix. Скрипт сравнивает текущий список запущенных процессов с ранее сохранённым «снимком». Если появляются процессы, которых не было ранее и которых нет в белом списке, формируется алерт, а база известных процессов обновляется

### Возможности

1. Сбор списка процессов с помощью ps и отсеивание системных потоков ядра
2. Фильтрация процессов по белому списку
3. Сравнение с сохранённым состоянием 
4. Отправка алертов в Zabbix через zabbix_sender при обнаружении новых процессов
5. Тихий режим работы при отсутствии новых процессов

### Плейбук playbook.yml выполняет:

1. Установку GPG-ключа репозитория Zabbix и обновление кэша apt
2. Установку пакетов: zabbix-sender, procps, gawk
3. Создание защищённой директории /etc/process_watchdog/ с правами 0700
4. Копирование скрипта в /usr/local/bin/process_watchdog.sh
5. Генерацию файла .env из шаблона
6. Настройку задания cron для запуска каждые 5 минут от имени root

### Белый список

Белый список предотвращает ложные срабатывания на легитимные процессы (cron, sshd, bash, nginx, mysqld и т.п.).

Путь по умолчанию: /etc/process_whitelist.conf

Формат: только имя исполняемого файла, без полного пути и аргументов. Одна строка — один процесс.Комментарии: строки, начинающиеся с #, игнорируются.

Правильно:

`text`

`python3`

`mysqld`

`node`

### Путь по умолчанию: /var/tmp/process_state.txt

Назначение: хранит снимок известных процессов. Используется /var/tmp, а не /tmp, чтобы файл сохранялся после перезагрузки.

### Переменные окружения (.env)

Файл конфигурации: /etc/process_watchdog/.env. Создаётся автоматически при деплое через Ansible.

|  Переменная	|Обязательная|	Описание
|---------------|------------|---------------------------------------------------------------------------------|
|ZABBIX_SERVER	|да	         |   IP или DNS-имя Zabbix-сервера/прокси                                          |
|ZABBIX_HOST	|нет	     |   Имя хоста в Zabbix. Должно точно совпадать с именем в веб-интерфейсе          |
|ZABBIX_KEY	    |нет	     |   Ключ элемента данных в Zabbix. По умолчанию: process.watchdog.new.alert       | 
|STATE_FILE	    |нет	     |   Путь к файлу сохранения состояния. По умолчанию: /var/tmp/process_state.txt   |
|WHITELIST_FILE	|нет	     |   Путь к файлу белого списка. По умолчанию: /etc/process_whitelist.conf         |
|ZABBIX_SENDER	|нет	     |   Путь к утилите отправки. По умолчанию: /usr/sbin/zabbix_sender                |
