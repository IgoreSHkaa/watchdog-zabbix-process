# Мониторинг новых процессов на сервере через Zabbix 

Bash-скрипт для обнаружения несанкционированных или новых процессов на Linux-сервере с автоматической отправкой алертов в Zabbix

Скрипт сравнивает текущий список запущенных процессов с ранее сохраненным состоянием. Если появляются процессы, которых не было ранее, скрипт формирует алерт и обновляет базу известных процессов

## Зачем нужен белый список (Whitelist)?

Белый список — это механизм предотвращения ложных срабатываний

Что писать в белый список?

Только имя исполняемого файла (без полного пути и аргументов)
```python3, mysqld, node```

Каждый процесс указывается с новой строки.

Строки, начинающиеся с #, считаются комментариями и игнорируются.
